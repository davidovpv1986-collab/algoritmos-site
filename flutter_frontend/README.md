# Flutter Web — Orbit

Самостоятельная реализация первого синего концепта сайта «Алгоритмос». Экран не использует внешние ассеты: 3D-подобный орбитальный объект нарисован через `CustomPainter` и анимирован средствами Flutter.

## Запуск

```bash
flutter pub get
flutter run -d chrome
```

## Production-сборка

```bash
flutter build web --release
```

Готовые статические файлы находятся в `build/web/`.
